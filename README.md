# hi

The contact page at https://njenga.ai/hi/. GitHub Pages serves this repository under the njenga.ai domain because its name is `hi`.
It is separate from the site repository on purpose: a site publish does not touch it.

This repository holds no phone number. The QR code carries the number in the part of the address after `#`, which a browser
does not send to a server. With that part, the page adds the number, a WhatsApp button and a contact card that includes the number.
Without it, the page offers a card without a number, LinkedIn and a link to the site.

Files: `index.html` (the page, self-contained), `njenga-kariuki.vcf` (the card without a number), `chivo-300-600.woff2` and `OFL.txt`
(the font and its licence).

Three places name the event and are due for a change after it: the `NOTE:` line in `njenga-kariuki.vcf`, and in `index.html`
the same `NOTE:` text and the WhatsApp message text.
